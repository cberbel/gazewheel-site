Frases prontas

Uma seleção só, em vez de escrever tudo. Toque numa frase para inserir no texto.

Ensinar o teclado a escrever como você

Cole aqui textos que você mesmo escreveu — reportagens, e-mails, posts — ou carregue arquivos de texto de uma vez (útil para quem já usa outro autocomplete calibrado: exporte seus textos de lá e traga tudo aqui). O teclado aprende suas palavras e, principalmente, quais palavras você costuma usar depois de quais. É o jeito mais rápido de reduzir o número de seleções por frase. Nada é enviado para a internet: fica salvo só neste navegador.

Ajustes

Pensado para quem controla o cursor com os olhos. Se o seu equipamento já faz o clique sozinho (Tobii Windows Control, por exemplo), deixe a seleção por permanência desligada para não haver dois tempos de espera.
